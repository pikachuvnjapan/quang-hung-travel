# Quang Hùng Travel

Website tĩnh cho dịch vụ xe đường dài Quang Hùng Travel.

## Chạy website

Mở index.html trong trình duyệt. Không cần cài thêm phần mềm hoặc build.

## GitHub Pages

Trong repository GitHub, vào **Settings → Pages**, chọn **Deploy from a branch**, branch **main**, thư mục **/(root)**, rồi lưu. Trang sẽ được xuất bản tại địa chỉ GitHub Pages của repository.
